# Butano scenario 41 战斗关卡

## 用户可见结果

ROM 冷启动后进入原作任务准备菜单。四行菜单可用方向键切换；选择“开始任务”并确认后进入 9×22 战场。鸣人从 `(4,10)` 出发，对手 character 30 从 `(4,4)` 出发，原 UI 显示其为木叶丸。

关卡完整包含四回合行动、教程对白、移动与朝向、术·忍具菜单、忍者组合拳目标与确认、264 帧战斗动画、战斗对白与弹窗、胜利、`100 / 50 / 0 = 150` 结算、鸣人升 LV2、两页成长信息、11 页战后对白和世界地图。

## 操作

| 按键 | 行为 |
|---|---|
| 方向键 | 移动光标；在任务、行动、确认菜单中移动选项；选择人物面对方向 |
| A | 确认当前选项、推进对白或结算 |
| B | B 取消当前层级；目标 → 术菜单 → 行动菜单 → 移动预览 → 单位选择 |
| START | 不提供全局快速待机；按下时播放无效反馈，不改变回合状态 |

## 可执行验收路线

自动黄金路线由 `tools/butano/mgba_scenario_41_golden_route.lua` 固定，手工操作遵循同一流程：

1. 冷启动后按 Down 两次选中“开始任务”，按 A；在“开始任务？”选择“是”并按 A。原作随后依次显示双方战场亮相、“开始”大字、鸣人与木叶丸的可见战前对白；读完对白再按 A，经过手里剑转场进入单位选择。
2. 选择鸣人，预览并提交移动，在行动菜单选择术·忍具或“行动结束”；结束行动后依次完成朝向和防御准备。
3. 推进第 2 回合教程对白，再按同样规则完成第 2、3 回合。
4. 第 4 回合把鸣人移动到 `(6,4)`；进入“术·忍具”，选择“忍者组合拳”，把目标对准 `(6,3)` 的木叶丸并确认“可以吗？ 是”。
5. 观察完整 264 帧组合拳；演出期间输入锁定。随后按 A 依次推进战斗对白、战斗弹窗和“胜利”。
6. 结果页应显示三项 `100 / 50 / 0 = 150`；继续后鸣人升到 LV2，体力 `+14`。
7. 推进 11 页战后对白，最终进入原作世界地图画面。

可在非第 4 回合、非相邻位置尝试提交忍者组合拳验证非法目标：操作被拒绝，单位位置、HP、回合和胜负状态不发生部分提交。移动预览中按 B 可验证暂存位置不会提前写回。

## 加载、空状态与错误

- 加载：图形、音乐和音效随 ROM 编译，运行时不访问网络或外部文件。
- 空状态：本纵切片固定包含鸣人和木叶丸，不开放空队伍；基础系统自检失败时在进入关卡前断言停止。
- 错误：越界、阻挡、占用、超移动力、非法目标与无效 START 都播放 sound 105，不改变已提交状态。
- 权限或数据缺失：GBA 无权限模型；缺失编译期资产会让构建失败，不在运行时静默使用占位资源。

## 音频路线

战前、战斗、组合拳、战后对白和世界地图依次使用原版 cue 5、cue 14、cue 15、cue 8、cue 2。BGM 使用从原 ROM mGBA checkpoint 实录得到的去直流 unsigned 8-bit、22050 Hz 单声道 Maxmod 资产；确认/取消/光标/无效操作和组合拳、弹窗、胜利、结果、升级事件使用从原 ROM player 状态闭合的对应音效。当前生产 ROM 冷启动宿主录音的 `>=8192` 相邻采样突跳为 0，2440 帧自动路线可完成全部战斗和战后流程；用户手工听感验收仍以文档记录的 ROM SHA-256 为准。

## 功能边界

- 2026-07-22 在线录屏复核确认：当前生产 ROM 错误跳过了双方亮相、“开始”标题、可见战前对白和手里剑转场。此前“确认是后直接进入单位选择”的验收结论已撤销；在入口序列按原作补齐前，本关不得标记为完整 1:1。
- 战前“队伍·装备”“查看地图”“保存”三行可选并保留原画面，但本纵切片不实现其子页面；确认时给出无效反馈。只有“开始任务”进入关卡。
- 本关只实现已证明的四回合成功路线和忍者组合拳；不包含全游戏多角色部署、其他技能、失败结算、通用 AI、旧存档兼容或其他章节。
- 旧路线的 39 个稳定画面没有覆盖正确入口序列，不能再作为完整流程验收；组合拳 264/264 帧的独立视觉证据仍有效。音频是原 PCM 与事件顺序的功能等价 Maxmod 实现，不声明逐采样 MP2K 等价。

构建、计时、哈希和 mGBA 证据见 `notes/butano-scenario-41-one-to-one-runtime-20260722.md`。
