### 0.2 ⭐ 为什么会这样：86% 的残差根本不是像素差

| 桶 | 帧数 | 残差总和 | 占比 |

| 产品差（同一时刻仍有渲染差） | 14 | 23,046 | 13.7 % |
| 一致 | 3 | 0 | 0 % |

⇒ **要残差归零，第一步不是改像素，是让两侧处在同一游戏时刻。**
⇒ wave 5 的一半火力放在**配对**上，不是放在像素上。
