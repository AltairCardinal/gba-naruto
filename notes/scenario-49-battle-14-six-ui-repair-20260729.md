# Scenario 49 / battle 14 六项 UI 修复记录（2026-07-29）

## 原因与设计

本轮问题不是六个互不相关的绘制缺陷，而是三类状态投影混用：

1. 字体消费者没有严格分层。剧情正文、说话者姓名、紧凑战斗菜单和完整目标详情曾共用
   不同尺寸假设的字形，造成对白过小或战斗文字越框。
2. 控制器完成攻击后仍把光标留在目标单位。地图镜头、头顶朝向、回合末面向提示都读取
   同一个光标，因而会错误聚焦敌人，甚至让玩家误以为面向阶段没有生效。
3. 决斗构图曾把“发起者/目标”误当成左右站位。原作录像证据实际按阵营固定：
   玩家在左朝右、敌人在右朝左；敌方先攻只改变动作角色，不交换双方位置。

修复后的长期约束：

- 剧情正文只用原 ROM 8×16 packed 字形；说话者和展开目标详情使用独立全高字形；
  紧凑战斗菜单继续使用 8×8 UI 字形，禁止跨角色复用。
- 移动、攻击和合法目标范围只由 controller snapshot 的 bit rows 投影。目标预览和
  确认不再清除范围；当前移动格/合法目标格使用独立高亮。
- 攻击结算保存目标坐标用于演出，但马上把交互光标恢复到行动者的实际落点。镜头、
  头顶四向指示和回合末面向都因此重新绑定同一行动者。
- 决斗画面固定玩家在左朝右、敌人在右朝左；发起者、地图相对 X 和旧面向都不参与
  决斗站位。
- 正常技能、直接攻击和“行动结束”都必须经过
  `facing_selection → defense_decision`，不能直接结束玩家回合。
