# 覆盖层「换原版图块」实验：两次都更差 ⇒ 缺的是**族 0 的网格网**（2026-10-21，第 21 轮）

## 1. 实验

前提（第 17–20 轮已闭合）：原版覆盖层 = BG2 + 32 块 4bpp 图块 + bank 12 调色板；
选块规则 = 「同族内按原版逻辑格的列奇偶」；重制侧一个格点 = 32×16 px = 原版的两个 16×16 逻辑格
（左偶列、右奇列）⇒ 每个格点的 4×2 图块排布固定。

于是把重制侧覆盖层的图块**换成原版的**（4bpp 展开成 8bpp，像素值 = 224 + 原版 bank 12 相对索引），
并按上述规则选块。落位方案选的是**零 VRAM 风险**的那个：原版 20 块高亮图块分别放进
重制侧 move/attack/cursor/target 四个角色**自己那 8 格**里的前 4 格（其余槽位不动），
**图块集总大小不变**（仍是 77 块 8bpp = 154 个存储单元 ⇒ VRAM 占用不变）。

## 3. 为什么「只换高亮图块」必然更差

原版 BG2 **在整张地图上铺满族 0 的图块**（1024 格全部引用 256–281），
族 0 = 常驻的**网格网**（细线，色 index 1）；移动范围那 212 格是在这张网之上**换成族 2**。
⇒ 原版屏幕上看到的是「**网 + 高亮块**」两层叠加。

重制侧的覆盖层只画「范围 + 它自己的网格」，**没有那张网**。
⇒ 单独把高亮块换成原版的（带边线、带相位差）而没有网，
画面既不是原来的平坦青、也不是原版的网+块 ⇒ 两头不讨好 ⇒ 像素变多。

⇒ ⇒ **⇒ 结论：换图块这件事不能单独做**。要让原版覆盖层 1:1，必须**一次性**把
「族 0 的网 + 族 2..10 的高亮块 + 选块规则」整套接上，而**族 0 的规则仍未闭合**
（grid16 收据上冲突 41、banner 冲突 2）。

## 4. 下一轮的最小可执行步骤

1. **先闭合族 0 的规则**（网格网的选块）：候选维度 = 线的绝对位置（与地图格线的对齐）、
   邻居族不同时的处理、或者「网是常驻底图、与高亮无关」的另一种解释。
   族 0 只在「有线的格」上冲突，**空白格族无冲突** ⇒ 可以先把空白部分做对。
2. 族 0 闭合后，**一次性**接上：族 0 的网 + 族 2..10 的高亮块 + 列奇偶规则。
3. 验收基线：与原版移动网格帧的差异应从 **2,917** 明显下降。

## 5. 顺带确认的两件事（对实施有用）

- **混合权重不用改**：原版 `BLDALPHA = 0x0A0A` ⇒ EVA=EVB=**10/16**，重制侧也是 10/16 ✓。
- **颜色不用改**：重制侧 `move_primary = RGB5(3,25,31)` **正是**原版 bank 12 的 index 2 ✓。
- **图块落位可以零 VRAM 风险**：原版 20 块高亮图块可以放进四个角色自己那 8 格里的前 4 格，
  图块集总大小不变 ⇒ 不触发 VRAM 压力（实验里已验证可行）。
