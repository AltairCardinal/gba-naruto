# Skill template 消费字段语义（2026-07-13）

> 2026-07-23 身份纠错：该 94×16 表是忍具/强化道具数值模板，旧目录名 `skills` 仅为兼容路径。下文控制流成立，但“技能/skill”实体名应替换为“忍具/ninja tool”，`+A/+B` 是忍具父子/候选关系。

## 结论

真实忍具模板为 file `0x545BE4..0x5461C3` 的 94×`0x10` 表。后续自然术列表
运行时闭环已把 bank 升级为 `runtime_verified`；本节原先闭合的五个关系字段仍有效，
详情数值的新结论见 `notes/natural-skill-detail-runtime-20260713.md`。

| ROM 字段 | 已证明语义 | 消费者 |
|---:|---|---|
| `+0x00` | 战斗对象显示/动画族 | `0x08078F16`、镜像 `0x080953B4` |
| `+0x0A` | 前置/父忍具 ID | `0x0808FF7C` |
| `+0x0B` | 可联动忍具候选 ID | `0x0808FF88` |
| `+0x0C` | 使用/目标资格白名单 ID 0；零表示不限制 | `0x0808FC20` |
| `+0x0D` | 可选的第二个资格白名单 ID | `0x0808FC20` |

## 消费链

`0x08078E38` 与镜像 `0x080952C8` 从角色候选区或 controller
`+0x70+slot*4` 取得 skill ID，按 `0x08545BE4 + skill_id*0x10` 索引并读取 `+0`。
非零值参与 `(value-1)*4` 的对象 `+0x10` 图块/帧索引计算，因此最保守名称是
`display_animation_family`。

`0x0808FF24` 从 controller 选中槽取得 skill ID，遍历 physical skill 1..93，将每条
`+0x0A` 与选中 ID 比较；命中后用 `+0x0B` 匹配 controller 候选 ID，并设置对应
eligible flag/count。若没有匹配，count 写为 `0xFF`；调用点 `0x0808E4A4` 随后可走
错误音 `0x69`。

`0x0808FC20` 用选中技能的 `+0x0C/+0x0D` 检查候选 ID。`+0x0C=0` 直接允许；否则
只要候选匹配两个字节之一即允许，均不匹配则拒绝。调用点 `0x08095CAA` 的拒绝路径
同样播放错误音 `0x69`。

  `+C/+D` 与允许/拒绝结果。

重要范围：`0x545BE4..0x5461C3`；关键调用点：`0x0808E4A4`、`0x08095CAA`。
