# Butano 战斗命令阻断运行计划

日期：2026-07-27

## 里程碑

1. 用 ROM 哈希、Thumb BL 目标和动作模板锁定 `0x3F` 的生产与阵营激活消费者。
2. RED：证明动作 80 命中后没有持久状态；证明六个 blocker 存在时单位仍可被选择。
3. GREEN：动作 80 写入正式状态；`battle_session` 的唯一资格谓词消费共享 blocker 集。
4. 集成：玩家选人/轮换跳过阻断单位，AI flow 拒绝阻断 actor，状态到期后恢复资格。
5. 空阵营：没有可行动单位时执行一次事务式 side-end，继续状态/对象/条件/脚本并切边。
6. 回归：运行证据分析器、相关宿主 C++、全量宿主门禁、devkitARM 构建和可复现 mGBA 路线。
7. 将证据、边界与未完成项同步到领域记录和路线图；不自动提交。

## 验收标准

- action 80 命中后存在 code `0x3F`、duration 4 的状态，miss 保持零写；
- `3F/3E/3D/0F/11/15` 任一状态都让 `select_unit` 拒绝并让轮换跳过；
- AI 对相同阻断 actor 返回 `invalid_actor`，session 与 RNG 均零写；
- status tick 到期后同一单位重新可选；
- 整侧被阻断时自动切边，不进入不可操作页面；battle 20 和全场景百回合压力测试不再停住；
- 生产代码不新增截图状态、关卡专用分支或 renderer 规则；
- ARM 构建和自然运行证据无 crash/trap；音频未验证时不得宣称音频修复。
