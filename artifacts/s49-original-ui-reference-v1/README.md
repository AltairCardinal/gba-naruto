### 字格网格（逐格反推并已写成测试）

菜单文字左对齐起点在屏幕 `x=16`，行距 `y=24 + row*16`，字距 `x=16 + col*8`：

| 坐标 | 字 |
| --- | --- |
| `(16,24)` | 移 |
| `(24,24)` | 动 |
| `(16,40)` | 术 |
| `(24,40)` | ・ |
| `(32,40)` | 忍 |
| `(40,40)` | 具 |
| `(16,56)` | 查 |
| `(24,56)` | 克 |
| `(32,56)` | 拉 |
| `(16,72)` | 休 |
| `(24,72)` | 息 |
| `(16,88)` | 行 |
| `(24,88)` | 动 |
| `(32,88)` | 结 |
| `(40,88)` | 束 |

反推方法：`render_command_menu_text()` 以 `menu_y = -8 - count*8` 定位每行，
Butano 文本原点换算到屏幕后行 0 落在 `y=24..39`，`count=5` 时行距 16；
字格间距由第 1 行「术・忍具」四个字的墨迹列反推为 8。

### 为什么不沿用旧的 action-menu-0.png

旧坐标 `移(12,24) 休(12,72) 息(20,72)` 整体**左偏 4 像素**，裁进了面板竖边框，
于是这两个格子被烘成一条 16 行全满的实心黑条——正是 S49 命令菜单里
「移動」「休息」左侧那道黑杠。旧源文件已随 `artifacts/` 清理丢失，
故以本文件替换。
